# Maawaz Labs Portfolio

A polished React + Vite portfolio site for Muhammad Maawaz, featuring modern glassmorphism UI and AI-focused 3D visuals.

## Features

- Responsive portfolio layout with hero, about, skills, projects, and contact sections
- Interactive 3D brain network visual in the hero section
- Animated neuron connection pulses 
- Built with React 19, Vite, Tailwind CSS, and Framer Motion
- `@react-three/fiber` + `@react-three/drei` for WebGL visuals
- Clean dark theme with neon accent styling

## Tech stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- React Three Fiber
- Drei
- Lucide React icons
- Three.js

## Project setup

```bash
npm install
npm run dev
```

Open the local development URL shown in the terminal to preview the site.

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Project structure

- `src/App.jsx` — main portfolio page layout and sections
- `src/components/visuals.jsx` — custom 3D brain and particle visuals
- `src/index.css` — global theme styles and Tailwind setup
- `package.json` — dependencies and scripts

## Notes

This portfolio is designed to showcase AI, machine learning, and modern web design through a dynamic hero section and refined content sections. The 3D brain network animation reinforces the neural messaging concept and makes the presentation more engaging.
